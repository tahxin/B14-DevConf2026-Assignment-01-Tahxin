# Dev Conf 2026 — Conference Landing Page

A modern, responsive conference landing page built as part of **B14 DevConf 2026 — Assignment 01**.

The project presents a fictional developer conference, **Dev Conf 2026**, with a clean and professional interface focused on developers, engineers, founders, and technology enthusiasts.

## 📌 Project Overview

Dev Conf 2026 is a static conference website designed to provide visitors with essential information about the event while maintaining a modern developer-focused visual identity.

The landing page includes:

* Conference hero section
* Navigation menu
* Speaker showcase
* Conference ticket pricing
* Newsletter subscription form
* Social media links
* Privacy Policy and Terms of Service links
* Custom conference branding and imagery

The project was developed using **HTML5 and CSS3** without a JavaScript framework or external frontend library.

---

## ✨ Features

### 🏠 Hero Section

The hero section introduces Dev Conf 2026 with the headline:

> **Code. Connect. Create**

It includes:

* Conference introduction
* Registration call-to-action
* Full-width background image
* Responsive centered layout

### 🎤 Meet the Speakers

A dedicated speaker section showcases four technology leaders across different technical domains:

| Speaker          | Track            | Role                               |
| ---------------- | ---------------- | ---------------------------------- |
| Andrej Karpathy  | AI/ML            | Pretraining Team Lead at Anthropic |
| Demis Hassabis   | Cloud and DevOps | Co-Founder and CEO at DeepMind     |
| Gary Marker      | Frontend         | Staff Engineer at Vercel           |
| Mustafa Sulayman | Security         | CEO of Microsoft AI                |

Speaker cards use custom images and a structured grid layout.

### 💳 Pricing Plans

The website provides three conference registration options:

#### Standard — `$399`

* Access to all 3 conference days
* 48 curated technical talks
* 2 workshop sessions
* Networking lunch & coffee breaks
* Conference swag bag
* Digital recordings for 30 days

#### Pro — `$749`

* Everything included in Standard
* Unlimited workshop access
* Speaker meet & greet
* VIP networking dinner
* Lifetime recording access
* 30-minute 1-on-1 mentorship

#### Team — `$5,999`

* Everything in Pro for up to 10 people
* Dedicated team lounge access
* Private workshop booking
* Company logo on event page
* Recruitment booth
* Priority customer support

The **Pro** plan is visually highlighted to emphasize it as the featured option.

### 📧 Newsletter Subscription

The project includes a newsletter section where visitors can enter their email address to receive:

* Conference announcements
* Speaker updates
* Exclusive offers

The form uses HTML email validation through the `required` and `type="email"` attributes.

### 🔗 Footer

The footer contains:

* Conference branding
* Social media icons
* Copyright information
* Privacy Policy link
* Terms of Service link

## 🎨 Design

The interface follows a minimal developer-conference aesthetic built around:

* Blue primary accent
* Dark navy sections
* White content areas
* Large typography
* Rounded UI elements
* Card-based content
* Grid and Flexbox layouts
* High-contrast call-to-action buttons

The primary visual accent is based around **`#2563EB`**, while dark sections use **`#0D1B2A`**.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/tahxin/B14-DevConf2026-Assignment-01-Tahxin.git
```

### 2. Navigate to the project

```bash
cd B14-DevConf2026-Assignment-01-Tahxin
```

### 3. Open the website

Since this is a static HTML/CSS project, no package installation or build process is required.

Simply open:

```text
index.html
```

in your browser.

Alternatively, you can use a local development server such as **VS Code Live Server**.
